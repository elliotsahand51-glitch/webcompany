# DANIEL — Digital Solutions & Web Platform

A luxury, high-performance web platform built with modern HTML5, Vanilla CSS, and JavaScript.

## 🌟 Highlights

- **Luxury Editorial Aesthetic**: Custom typography pairing Playfair Display and Plus Jakarta Sans with subtle micro-interactions.
- **Fluid & Fully Responsive**: Tailored layouts across ultra-wide, desktop, tablet, and mobile screens.
- **Showroom & Portfolio**: Showcase of digital craft, enterprise web apps, CMS, CRM, and POS platforms.
- **Zero-Bloat Performance**: Built using pure HTML5, modern CSS custom properties, and vanilla JavaScript.

## 📁 Project Structure

```
├── assets/             # Brand logos, photography, and showcase imagery
├── index.html          # Main landing page & showcase
├── index.css           # Core design system & responsive styling
├── main.js             # Interactive behaviors, mobile menu & animations
├── about.html          # Company story and philosophy
├── server.js           # Lightweight Node.js local preview server
└── .gitignore          # Repository ignore rules
```

## 🚀 Getting Started

### Local Preview

You can open `index.html` directly in any web browser, or launch the included Node.js server:

```bash
node server.js
```

Then navigate to `http://localhost:3000` in your browser.
